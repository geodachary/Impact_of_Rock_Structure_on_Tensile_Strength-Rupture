RELEASE TITLE
=============

Impact of Rock Anisotropy on Tensile Strength and Modes of Rupture


RELEASE NOTES
=============

This release contains the analysis code, the raw measurements and the cached
field archives that reproduce every table and figure of the associated
manuscript from the laboratory data.

This is the archive of record for the associated manuscript. An earlier
deposit under the same concept record was cut from a superseded tag and
contained the data and figures but none of the analysis code; it cannot
reproduce the reported results and should not be used.


WHAT IS INCLUDED
----------------

  368 files, comprising

  tools/                68 modules: orthotropic Lekhnitskii Airy-series stress
                        solution, four-class failure classification, fabric
                        tractions, crack-path stepper, strain-energy
                        partitioning and the supporting mechanics helpers
  scripts/              28 generators, including one-command reproduction
  tests/                69 test files
  three notebooks       one per lithology and one for the cross-lithology
                        comparison
  crack_digitized_data/ 14 digitized post-failure fracture traces
  outputs/fields/       14 cached field archives, so the validation tables and
                        figures can be rebuilt without the multi-hour notebook
                        run
  raw measurements      Brazilian tensile strengths, uniaxial and triaxial
                        results for both lithologies


SCOPE
-----

Brazilian tensile tests on two foliated metamorphic rocks, an augen gneiss and
a psammitic schist, at seven fabric orientations from 0 to 90 degrees. The
workflow solves the orthotropic stress field for a transversely isotropic
disc, classifies failure pointwise by mechanism and locus, traces diagnostic
crack trajectories and partitions strain energy across the resulting classes.


REPRODUCING THE RESULTS
-----------------------

  python -m pip install -r requirements.txt
  python scripts/execute_notebooks.py     # first run only; builds the caches
  python scripts/reproduce_all.py --mode full

The first command needs Python 3.10 or newer. On a clean clone the notebooks
must run before reproduce_all, because the mid-plane displacement cache is
keyed on a hash of the specimen geometry and material and is deliberately not
committed. Once the caches exist, reproduce_all completes in under a minute.

Verified end to end from a bare checkout: the notebooks build all four solver
caches, reproduce_all completes and reports an orientation mean absolute error
of 3.35 degrees over the fourteen specimens, and the test suite passes with no
failures. Tests that compare the manuscript prose against the outputs skip on
a clean clone, because the manuscript source is not part of this release.

Figures are byte-reproducible: SOURCE_DATE_EPOCH is pinned, so regenerating an
unchanged figure returns an identical file.


WHAT THIS ARCHIVE PROVIDES
--------------------------

  - the complete analysis layer, absent from the superseded deposit
  - elastic constants identified in the foliation frame: one material-axis set
    per lithology, with the in-plane shear modulus identified from the measured
    off-axis directional stiffness rather than read from an on-axis test
  - symmetric trace-comparison protocol: the digitized and modelled traces are
    read over one common interior, r <= 0.85R, and scored against a
    loading-parallel null predictor
  - regression suite covering the reported values against the outputs they are
    drawn from
  - reproduction scripts fail with an actionable message when a prerequisite
    cache is absent, rather than with an unrelated error further downstream
